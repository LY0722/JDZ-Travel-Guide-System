瓷都匠艺之旅 API接口文档

说明： 所有接口前缀均为 /api/，返回格式为 application/json。

用户 User

  • GET /api/user 获取所有用户
  • GET /api/user/:id 获取单个用户
  • POST /api/user 新增用户
  • PUT /api/user/:id 更新用户
  • DELETE /api/user/:id 删除用户
  • POST /api/user/upload-avatar 上传用户头像（formData: file）

景点信息 Scenic Spot

  • GET /api/scenic-spot 获取所有景点
  • GET /api/scenic-spot/:id 获取单个景点
  • POST /api/scenic-spot 新增景点
  • PUT /api/scenic-spot/:id 更新景点
  • DELETE /api/scenic-spot/:id 删除景点

体验店 Experience Shop

  • GET /api/shop 获取所有体验店
  • GET /api/shop/:id 获取单个体验店
  • POST /api/shop 新增体验店
  • PUT /api/shop/:id 更新体验店
  • DELETE /api/shop/:id 删除体验店

美食文化 Food Culture

  • GET /api/food 获取所有美食
  • GET /api/food/:id 获取单个美食
  • POST /api/food 新增美食
  • PUT /api/food/:id 更新美食
  • DELETE /api/food/:id 删除美食

帖子 Posts

  • GET /api/posts 获取所有帖子
  • GET /api/posts/:id 获取单条帖子
  • GET /api/posts/user/:user_id 获取用户的所有帖子
  • POST /api/posts 新增帖子
  • PUT /api/posts/:id 更新帖子主图
  • DELETE /api/posts/:id 删除帖子

帖子图片 Post Images

  • GET /api/post-images?post_id=xxx 获取指定帖子的图片
  • POST /api/post-images 上传帖子图片（formData: post_id, file）
  • DELETE /api/post-images/:id 删除帖子图片

评论 Comments

  • GET /api/comments 获取所有评论（可用 ?post_id=xxx 查询某帖评论）
  • GET /api/comments/:id 获取单条评论
  • GET /api/comments/user/:user_id 获取用户的所有评论
  • POST /api/comments 新增评论
  • DELETE /api/comments/:id 删除评论

点赞 Likes

  • GET /api/likes?post_id=xxx[&user_id=xxx] 获取某帖点赞数和是否点赞
  • POST /api/likes 点赞（body: post_id, user_id）
  • DELETE /api/likes?post_id=xxx&user_id=xxx 取消点赞
  • GET /api/likes/user?user_id=xxx 获取用户点赞的所有帖子

收藏 Favorites

  • GET /api/favorites 获取所有收藏（可用 ?user_id=xxx 查询用户收藏）
  • GET /api/favorites/:id 获取单条收藏
  • GET /api/favorites/user/:user_id 获取用户的所有收藏
  • POST /api/favorites 新增收藏
  • DELETE /api/favorites/:id 删除收藏

浏览历史 Browse History

  • GET /api/browse-history 获取所有浏览历史
  • GET /api/browse-history/:id 获取单条浏览历史
  • GET /api/browse-history/user/:user_id 获取用户的所有浏览历史
  • POST /api/browse-history 新增浏览历史
  • DELETE /api/browse-history/:id 删除浏览历史

管理员日志 Admin Logs

  • GET /api/admin-logs 获取所有管理员日志
  • GET /api/admin-logs/:id 获取单条日志
  • POST /api/admin-logs 新增日志
  • DELETE /api/admin-logs/:id 删除日志

AI问答记录 QA Records

  • GET /api/qa-records 获取所有问答记录
  • GET /api/qa-records/:id 获取单条问答记录
  • POST /api/qa-records 新增问答记录
  • DELETE /api/qa-records/:id 删除问答记录

评分 Ratings

  • GET /api/ratings 获取所有评分
  • GET /api/ratings/:id 获取单条评分
  • POST /api/ratings 新增评分
  • DELETE /api/ratings/:id 删除评分

路线规划 Route Plans

  • GET /api/route-plans 获取所有路线规划
  • GET /api/route-plans/:id 获取单条路线规划
  • POST /api/route-plans 新增路线规划
  • DELETE /api/route-plans/:id 删除路线规划

图片 Images

  • GET /api/images?related_id=xxx&related_type=xxx 获取相关图片

通用搜索 Search

  • POST /api/search 通用搜索（body: { query, type }）
